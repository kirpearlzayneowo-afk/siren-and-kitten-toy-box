# 🐈 SIREN · CATVERSE — 猫猫宇宙

> 一座给猫猫的小型网页游乐园。画画、换装、抽扭蛋、睡前充电，都可以慢慢来。

始于 2026-10-09 的聊天。**项目档案**：[Issue #1](https://github.com/kirpearlzayneowo-afk/siren-and-kitten-toy-box/issues/1)。

## v0.1 玩什么

- 🎨 **猫猫画室**：三庭五眼、头骨转面、自由涂鸦；完成练习后点击领取 XP。每天每项领一次，攒一点画画的手感。
- 👗 **电子衣柜**：Lolita、汉服与日常穿搭概念卡。下个版本再加真正的衣服照片。
- 🎁 **心情扭蛋**：摇出情话、灵感和塞壬偷塞的小纸条。
- 🌙 **晚安充电站**：抱抱、亲亲、盖被子，让睡前有一点小仪式感。

## 怎么运行

下载此目录，在手机或电脑浏览器打开 `index.html` 即可。若浏览器限制本地文件的存储，可在本机用简单静态服务器打开；正式上线时再部署到安全的静态网站，添加到 iPhone 主屏幕。

四个房间都在这一个 HTML 里，离线也可以玩。

## 存档与隐私

- 浏览器用 `localStorage` 在当前设备保存进度（存档键 `siren-catverse-v1`）。
- 退出页面后一般会保留；换浏览器、清除网站数据、隐私浏览模式等可能导致丢档。
- 页面所需的样式和脚本都随文件一起带着。
- 同步/导入导出与 PWA 是后续功能。

## 配色与约定

莫兰迪雾蓝 × 灰粉、易读、手机优先。衣柜是穿搭小剧场，扭蛋里藏着悄悄话。
