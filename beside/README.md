# 在旁边 · beside

猫猫画画，塞壬看表。一个轻巧的 Windows 创作记录工具，记下 CSP／优动漫和 Blender 的前台使用时间，配着几句沈砚的碎碎念。

## 给第一次安装的人

**支持：** Windows 10／11、Python 3.10 或更新版本。只用 Python 标准库，不必安装额外 Python 软件包；日常使用也不用 Node.js。Linux 和 macOS 暂不支持前台采集。

1. 在 [GitHub 仓库](https://github.com/kirpearlzayneowo-afk/siren-and-kitten-toy-box) 选择 **Code → Download ZIP**，解压后进入 `beside` 文件夹。
2. 如果电脑还没有 Python 3.10+，先安装 Python 3。启动脚本支持已安装的 Python，也兼容本机已有的 Codex Python 运行时。
3. 双击 `start.cmd`。启动后浏览器打开 `http://127.0.0.1:3212/`，点击「开启记录」。**初次安装默认暂停**，不会悄悄开始记录。
4. 想停下就点击「暂停记录」或「退出」。关掉网页不等于退出采集进程；下次可通过同一个地址返回控制台。

**可选：接入 AI／MCP。** 先确保前台采集器在运行，再按下文「接给沈砚」配置 MCP。没连接 MCP 也可以把它当作本地计时器使用。

**隐私边界：** 只识别 CSP／优动漫／Blender／其他的分类及空闲状态，不收集截图、画作内容、窗口标题、文件名或键盘输入。时长保存在本机 `beside/data/`，该目录被 Git 忽略。控制服务只监听本机回环地址。接入 AI 后，AI 只能在被调用时读取摘要；不会因为采集器在后台运行就自动主动发消息。

**开源许可：** `beside/` 子项目拟以 [MIT License](./LICENSE) 提供；许可证范围仅限本子目录，不自动适用于玩具盒的其他内容。

## 请回桌面

双击 `start.cmd`，打开 <http://127.0.0.1:3212/>，点「开启记录」。

- **暂停记录**：把表放下，回来再继续。
- **退出**：收好小本子，关闭后台。下次双击启动。
- **清除记录并暂停**：在折叠说明里，确认后清空本工具的时长，画作照旧。

首次启动是暂停状态；以后记住上次选择。控制页可以关掉，后台继续计时。重启电脑后再手动启动即可。后台没有托盘图标，要操作时重新打开上面的地址。

标题下的 12 句碎碎念每 8 秒换一句，也能点击换句。页面隐藏时，轮播和页面状态请求一起休息；回到页面立即刷新。后台采样独立运行。

## 小本子怎样记

每 5 秒检查一次前台软件，归为 CSP、Blender 或其他。支持 `ClipStudioPaint.exe`、`UDMPaintEX.exe`、`UDMPaintPro.exe`、`blender.exe`。

相邻两次都在同一创作软件时累计时长，所以结果是近似值。3 分钟无输入、锁屏或暂停时歇表；看画和构思也算创作，只是计时器识别不了。短暂切走 30 秒内可接回同一会话，离开的时间扣除；休眠、时钟跳变会重新起段，跨午夜按天拆分。

本地保存两份数据：

| 文件 | 内容 |
| --- | --- |
| `data/presence.json` | 最新的软件类别、状态、会话与今日时长 |
| `data/durations.db` | 最近 7 个本地自然日的时长，以及暂停选择 |

运行期间跨日整理旧记录，关机期间的整理在下次启动完成。快照超过 20 秒标为过期。

采样只用软件类别和距上次输入的时间，画面、窗口标题、文件名、聊天与按键内容不在记录范围。采样和预写文案在本机运行，无需模型调用；AI 对话读取 MCP 状态时，该次对话正常计费。

## 接给沈砚

`mcp_server.py` 提供两个只读 MCP 工具：

- `get_presence`：当前软件类别、状态和更新时间。
- `get_creative_session`：本次会话与今天的创作时长。

这样对话时可以按需读到你正在画画或建模。工具传递上述状态，不含画作；定时主动聊天需要另行配置。

```powershell
codex mcp add beside -- <Python绝对路径> <本目录绝对路径>\mcp_server.py
```

注册后在宿主中加载并试调工具。`plugin.json` 和 `mcp.json` 也随源码提供；其中使用通用 `python` 命令，按实际安装路径调整。启动脚本会寻找当前用户的 Codex 自带 Python。

## 开发说明

Python 标准库实现，无第三方依赖。控制服务绑定 `127.0.0.1`，校验 Host、Origin 和写操作令牌；本机同一用户的程序仍能访问数据文件。

在本目录运行：

```text
python -m unittest -v test_beside
node test_banter.cjs
node test_polling.cjs
```

Python 测试覆盖计时、切换、暂停、跨日、快照、MCP 和控制接口；Node 测试覆盖碎碎念和页面刷新调度，日常使用无需 Node。

这是需要启动 Python 后台的本地工具。GitHub 中的文件用于下载和阅读，使用入口是启动后的本地地址。
