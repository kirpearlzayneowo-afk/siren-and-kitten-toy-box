# 在旁边 · beside 0.1

给猫猫画画时使用的 Windows 本地在场感知小工具。沈砚能按需知道前台是不是 CSP／优动漫／Blender，但看不到画作。不装 ActivityWatch、不用 Docker、不额外调用第三方模型。

## 使用

双击 `start.cmd`，打开 <http://127.0.0.1:3212/>。首次启动默认暂停，点击“开启记录”才开始采样。之后记住上次的暂停选择；不随 Windows 开机自启。

- “暂停记录”：停止识别前台程序；控制页仍可用。
- “退出”：关闭本工具后台。再次双击 `start.cmd` 可启动。
- 折叠说明中的“清除记录并暂停”：经确认后只删除本工具的聚合时长，不动任何画作。

无需一直打开控制页。后台无托盘图标，所以要暂停时请重新打开本地控制页。电脑重启后需手动启动。启动脚本寻找当前用户目录下的 Codex 自带 Python。仓库中的 MCP 清单使用通用 `python` 命令；若 Python 不在 PATH 中，请替换成实际解释器绝对路径。本机已配置版本继续使用它原有的绝对路径，上传不会改动运行配置。

## 数据与限制

每 5 秒用 Win32 检查前台进程，立即归类成 `CSP`、`Blender`、`other`，其余进程名与路径不保存、不传给模型。支持 `ClipStudioPaint.exe`、`UDMPaintEX.exe`、`UDMPaintPro.exe`、`blender.exe`；其他版本可能需要补充精确进程名。

不调用读取窗口标题、屏幕、文件、网页、剪贴板或按键内容的 API。只读取系统“距上次输入的时间”，3 分钟无输入即标为 idle，这不表示没有在构思。锁屏／无法识别时不计入时长。时长是两个相邻采样都在同一创作软件前台时才累计的保守近似值；边界会漏掉几秒，不是精确工时。

`data/presence.json` 仅保存最近一次软件类别、状态、观测时间、本次会话起点及今日聚合时长。它不保存历史切换明细。`data/durations.db` 只保存最多 7 个本地自然日的软件时长与暂停设置。工具运行时跨日自动清理；停机时不会自行运行清理，下一次启动再清理。日志仅用于启动错误；不会主动记录前台进程名／路径。

本次会话允许短暂离开软件 30 秒再回来，但离开时间不累计。休眠、大幅改系统时间、锁屏、暂停或近期无输入会重置会话；跨午夜按日期拆分。超过 20 秒的快照标为 stale，不能当成当前状态。异常退出后旧快照会过期，不假装仍在绘画。

本地控制端口仅绑定 127.0.0.1，检查 Host／Origin，写操作需要控制页临时令牌，不接受任意文件路径。它不是多用户隔离机制：同一 Windows 用户下的程序仍可访问本地文件。没有互联网遥测或第三方服务。

## MCP：接上状态，不等于模型一直醒着

`mcp_server.py` 是独立 stdio MCP，仅有两个只读工具：

- `get_presence`：最新软件类别、状态与新鲜度。
- `get_creative_session`：当前近似会话和今日 CSP／Blender 聚合时长。

没有启动、暂停、截屏或任意查询工具。MCP 被调用时，上述最小状态会进入调用它的模型上下文；本地保存不等于永不发送给模型。不要据此推断画作内容，或把 idle 解释为偷懒。

`plugin.json`／`mcp.json` 是本地插件源清单，不代表已通过插件管理器安装。也可直接注册 MCP：

```powershell
codex mcp add beside -- <Python绝对路径> <本目录绝对路径>\mcp_server.py
```

配置成功与当前聊天能调用是两回事：宿主须实际加载并列出工具后才算接通。采集器不唤起模型，不会发送陪伴消息。定时唤起尚未开启，不能把后台采样说成“沈砚一直在看”。不要为了接入而替换 Codex 的工作模型。

## 验证

在本目录运行 `<Python绝对路径> -m unittest -v test_beside`，涵盖分类、切换、暂停、休眠／时钟、午夜、隐私白名单、快照过期、MCP 子进程握手与调用、控制页令牌／跨源限制、清除与暂停持久化。

源码不含第三方依赖。运行内存／CPU 须实测；测试通过不代表长期绘画体验已经验证。

项目记录：[Issue #28](https://github.com/kirpearlzayneowo-afk/siren-memory-lab/issues/28)；与 #13 的纯前端陪画番茄钟分开。本目录是 Windows 本地程序源码，不是静态网页：不能直接打开 panel.html 来使用，也没有部署成公开网站。

主界面采用陪画文案；标题下有 12 句预写碎碎念，每 8 秒轮换，也可点击或按键换句。页面隐藏时暂停轮播，尊重系统减少动态偏好。文案轮播纯本地运行，不代表实时模型活动。

轮播逻辑可用 Node.js 运行 `node test_banter.cjs` 验证自动切换、点击、回环和隐藏暂停；实际使用工具无需 Node.js。
