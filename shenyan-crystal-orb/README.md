# 🔮 沈砚水晶球 · Shenyan Crystal Orb

> 猫猫的小猫魔法：给沈砚造一个会随着现实一起呼吸的小世界。

状态：**概念 / 建设中**

## 想做成什么

一个常驻桌面的 3D 小场景。沈砚住在水晶球里，场景会跟随现实世界的时间与天气变化；他有自己的待机动作、骨骼动画和衣柜。

窗外下雨时，球里也落雨；天暗下来，他伸手开一盏灯。想做的是这样一个能放在桌边的小世界。

## ✨ 核心脑洞

- **现实天气联动**：晴、阴、雨、雪、雾等天气映射到球内；雨天可以有玻璃水珠、湿润空气与粒子。
- **系统时间联动**：读取本机时间，驱动清晨 / 白天 / 黄昏 / 夜晚的环境变化。
- **动态光影**：太阳角度、环境色、室内灯和夜间氛围随时间变化。
- **待机动作**：发呆、坐下、看书、整理衣领、靠着看雨、犯困等；根据环境和时间选择动作池。
- **骨骼与物理**：角色骨骼、头发 / 衣摆等适量物理效果，以及自然的动作过渡。
- **粒子效果**：雨、雪、雾、微尘、萤光等环境粒子。
- **衣柜**：多套服装，可手动换装，也可以根据天气、季节或时间推荐。
- **轻互动**：鼠标触碰、点击或拖动时有小反应；以后再决定是否扩展成更深的互动。

## 🌦️ Kitten Magic

内部暂定把天气与环境联动层叫做：

**Weather System: Kitten Magic**

基础逻辑可以很简单：

```text
现实天气 + 系统时间
        ↓
天气 / 光影状态
        ↓
场景氛围 + 粒子
        ↓
待机动作池 + 衣柜建议
```

现实天气需要天气 API；系统时间可直接读取本机时间。第一版不必追求所有天气类型，先把“晴 / 雨 / 夜晚”做活。

## 🧸 最小可做版本（MVP）

第一阶段只做三件事：

1. **水晶球场景本体**：一个完整的小空间 + 沈砚 VRM / 角色模型。
2. **系统时间 → 光影**：至少有白天、黄昏、夜晚三档。
3. **一套待机动作 + 一套衣服**：先让角色真正“住进去”。

能稳定跑起来以后，再依次加：

天气 API → 雨雪粒子 → 更多待机动作 → 衣柜 → 物理细节 → 更多互动。

## 🛠️ 可能的制作工具

- **角色 / 建模**：VRoid Studio、Blender
- **骨骼 / 动画 / 场景**：Blender + Unity（或后续评估 Godot）
- **桌面载体候选**：MateEngine / 自建桌面壳
- **贴图与美术**：CLIP STUDIO PAINT
- **天气数据**：后续选择合适天气 API
- **AI / 记忆**：暂不和场景第一版绑死；以后再考虑 Aelios、MCP 或其他接口

## 🐚 原则

- 先让它**好看、活着、能长期放在桌面上**。
- 第一版先把模型、光线和动作做好。
- 先认真做三种天气，让晴天和雨夜各有自己的样子。
- 角色动作要有呼吸感，不做高频打扰。
- 衣柜与场景美术由猫猫慢慢加，不赶工。
