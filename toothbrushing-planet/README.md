# 猫猫的刷牙星球 🫧

一只会陪猫猫刷牙的小牙齿。单文件离线网页，手机、电脑都能打开。

## 玩法

- 选择 **2 分钟** 或 **3 分钟** 刷牙模式。
- 点击开始，按分区提示换刷牙区域（2 分钟模式每 30 秒，3 分钟模式每 45 秒）；可以暂停、重来、开关提示音。
- 刷完会收到一颗珍珠。珍珠数量只保存在当前浏览器的 localStorage 中。

## 打开方法

下载本目录的 [index.html](./index.html)，在浏览器中打开；无需安装或联网。

刷的时候请保持页面打开、屏幕亮着，才能及时收到换区提示。后台挂起后，回到页面会更新剩余时间；珍珠存档跟着当前浏览器走。
