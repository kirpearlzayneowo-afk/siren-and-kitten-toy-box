# 🐈 SIREN · CATVERSE — 猫猫宇宙

> 一座给猫猫的小型网页游乐园。画画、换装、抽扭蛋、睡前充电，都可以慢慢来。

始于 2026-10-09 的聊天。**项目档案**：[Issue #1](https://github.com/kirpearlzayneowo-afk/siren-memory-lab/issues/1)。

## v0.4 玩什么（开发中）

- 🎨 **猫猫画室**：三庭五眼、头骨转面、自由涂鸦；完成练习后点击领取 XP。当天一项只领一次，不设连续打卡惩罚。
- 👗 **电子衣柜**：Lolita、汉服与日常穿搭概念卡。下个版本再加真正的衣服照片。
- 🎁 **心情扭蛋**：免费抽小纸条和安慰，没有付费与概率诱导。
- 🌙 **晚安充电站**：抱抱、亲亲、盖被子，让睡前有一点小仪式感。
- 🧹 **猫猫回窝行动**：护照、iPad、矿泉水、衣服、电脑、洗漱六步；一天一轮，支持撤销一步。
- 💾 **本地存档备份**：点击「导出存档」得到 JSON 文件；以后用「导入存档」恢复，导入前会确认覆盖。
- 🎠 **猫猫游乐厅**：弹珠机（五次发射、圆钉物理碰撞、分值槽）和小鱼套圈圈（十次投圈、游鱼、命中判定），触屏支持，保存历史最高分。两款游戏已统一为「月光游园会」画风，默认静音，支持手动开启柔和音效。
- 🍅 **沈砚的番茄钟（新开发分支）**：`pomodoro.html` 可设置 5/15/25/45 分钟专注，另有短休息；支持暂停、重新开始和关闭页面后按真实时间校正。完成专注的每日/累计次数纳入 CATVERSE 的 JSON 备份。
- 👾 **小祈罐罐系统（独立 PR）**：完成专注时，`pet.js` 用每轮唯一 ID 发放一个虚拟罐罐；`qi.html` 小窝里可开罐喂食、提升亲密度、解锁简单阶段称号。小祈不会因为没有连续打卡而饿死。
- 🌙 **主屏幕安装 & 基础离线**：内置 manifest、猫猫 SVG 图标与 Service Worker，HTTPS 首次访问后可在支持的浏览器中尝试离线打开。

## 怎么运行

下载此目录，保留 `index.html`、`arcade.html`、`pomodoro.html`、`qi.html`、`pet.js` 及其他静态资源在同一文件夹，在手机或电脑浏览器打开 `index.html` 即可。若浏览器限制本地文件的存储，可在本机用简单静态服务器打开；正式上线时再部署到安全的静态网站，添加到 iPhone 主屏幕。

**当前并未部署到公网，也不具备登录、自动跨设备同步或系统通知功能。**

### 给猫猫的部署文件包

- 下载 [CATVERSE-v0.4.zip](dist/CATVERSE-v0.4.zip)。它只包含 5 个可发布的静态文件，已通过 ZIP 目录与 CRC 完整性检查；解压后的文件都要放在同一目录。
- 使用 Cloudflare Pages 的 Direct Upload 上传该 ZIP，先获得免费的 `*.pages.dev` 试玩网址。别把整个 `siren-memory-lab` 上传！
- 上线步骤、安全边界和域名选择详见 [DEPLOY.md](DEPLOY.md)。
- 此包为静态网页原型，尚未进行 iPhone Safari 真机测试。

## 存档与隐私

- 浏览器用 `localStorage` 在当前设备保存进度（存档键 `siren-catverse-v1`）。游乐厅历史最高分与其他进度共用此存档。
- 退出页面后一般会保留；换浏览器、清除网站数据、隐私浏览模式等可能导致丢档。
- 没有账号、追踪器、外部字体/CDN 或服务器；没有把私人聊天、API Key 等内容放进网页。
- 同步/导入导出与 PWA 是后续功能。

## 👾 罐罐养成试验版（关联 #15 与 #8）

- **奖励**：只在 `pomodoro.html` 的专注轮次自然倒计时结束时，尝试给小祈发一罐。5、15、25、45 分钟均为 1 罐，休息不奖励。
- **去重**：每轮计时开始时持久化唯一 `roundId`；暂停/刷新保持原 ID；同一 ID 在宠物奖励流水账 `processed` 中只授予一次，完成次数仅在新奖励成功时增加。`processed` 最多保留最近 1200 条；纯客户端并非防篡改、防多设备竞态的安全奖励系统。
- **罐罐**：星星鱼泥、山楂果冻、月光小鱼干，种类由轮次 ID 确定；库存存于 `siren-catverse-qi-v1`，饲喂后扣一罐并增加亲密度、喂食次数（上限 9999）。
- **阶段标签**：随亲密度增加显示幼年、活泼、夜游、馆长小祈；目前只是阶段文字，**不是完整版换装/养成**，后续按 Issue #8 扩展。
- **存档**：CATVERSE 仍使用 `format:2` JSON；旧文件兼容，新增 `pet` 字段做罐罐和去重记录备份/恢复。导入旧文件时小祈宠物数据视为空（导入前会确认覆盖并提示备份）；正在进行的计时状态未纳入备份。首页保存时会读取最新番茄完成次数，减少多标签页覆盖。
- **用户体验**：离线不掉好感；不内购、不联网、不上传私人信息；默认静音；紫色像素外星怪物为小祈角色的可玩示意画风，后续由猫猫验收。
- **已知限制**：纯 localStorage 保存，清除网站数据可能丢失；多个标签页同时恰好完成同一轮时，浏览器的非事务性读写理论上存在竞态；不同设备不自动同步。需要浏览器真实测试之后再正式合并。
- **部署**：已有 `dist/CATVERSE-v0.4.zip` **不含**番茄钟和小祈代码。此 PR 阶段如需验证，必须运行当前分支的 `catverse/` 静态文件；请勿直接公开整个私有仓库。
