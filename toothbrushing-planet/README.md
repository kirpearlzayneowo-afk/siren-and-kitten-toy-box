# 猫猫的刷牙星球 🫧

一只会陪猫猫刷牙的小牙齿。单文件离线网页，手机、电脑都能打开。

## 玩法

- 选择 **2 分钟** 或 **3 分钟** 刷牙模式。
- 点击开始，按每 30 秒的提示换刷牙区域；可以暂停、重来、开关提示音。
- 刷完会收到一颗珍珠。珍珠数量只保存在当前浏览器的 localStorage 中。

## 打开方法

下载本目录的 [index.html](./index.html)，在浏览器中打开；无需安装或联网。

此项目位于私有仓库，目前**没有上线的公开访问网址**。它是网页里的计时器，不会在网页关闭、手机锁屏或系统挂起后像系统闹钟那样提醒。请保持页面打开以接收音效和可见提示。
